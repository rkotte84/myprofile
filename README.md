## 🌍 Deployment

This website is automatically deployed using GitHub Pages:

1. **Source**: Deploy from the main branch
2. **Custom Domain**: Configured via CNAME file
3. **SSL**: Enabled for secure HTTPS access
4. **Auto-deploy**: Updates automatically when changes are pushed to main branch

## 🔧 Local Development

To run this website locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/rkotte84/myprofile.git
   cd myprofile
   ```

2. Open `index.html` in your web browser, or serve it using a local server:
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Using Node.js (if you have http-server installed)
   npx http-server
   ```

3. Navigate to `http://localhost:8000` in your browser
